# Version del entorno que compilo firmware.bin / bootloader.bin / partitions.bin (original_laptop)

## Lo VERIFICADO (sacado directo del binario, no supuesto)
Cadena embebida encontrada en firmware.bin (buscada con un escaneo de strings ASCII):

    esp-idf: v4.4.7 38eeba213a

Esto corresponde a **ESP-IDF v4.4.7** (el commit corto 38eeba213a es el hash de IDF usado por ese
build de arduino-esp32). IDF 4.4.x es la base del "Arduino core 2.0.x" para ESP32 (framework
`framework-arduinoespressif32`), consistente con lo que reporto la sesion de la RPi (core 2.0.14),
pero el string del binario NO dice el numero de parche exacto del core de Arduino (2.0.11, 2.0.14,
etc. todos pueden embeber IDF 4.4.7) -- **no se puede afirmar el numero de patch exacto del core
solo con este dato.**

El binario tambien contiene rutas de compilacion como:

    C:/Users/Libra/.platformio/packages/framework-arduinoespressif32/...

-> Se compilo bajo el perfil de Windows "Libra", **no el de esta sesion (usuario "chees")**. Esa
carpeta `C:\Users\Libra\.platformio\` no existe en esta maquina (verificado: `ls` da "No such file
or directory") -- o se compilo en otra maquina, o en otro perfil de usuario de la misma maquina que
ya no esta aqui. **No se puede reconstruir el entorno exacto (version de platform `espressif32`,
version exacta del framework, version del toolchain) desde esta sesion.**

    |-- tool-mklittlefs @ 1.203.210628 (required: platformio/tool-mklittlefs @ ~1.203.0)
    |-- tool-mkspiffs @ 2.230.0 (required: platformio/tool-mkspiffs @ ~2.230.0)
    `-- toolchain-xtensa-esp32 @ 8.4.0+2021r2-patch5 (required: espressif/toolchain-xtensa-esp32 @ 8.4.0+2021r2-patch5)

**ESTO NO ES LA VERSION QUE COMPILO firmware.bin.** `espressif32 @ 7.0.1` usa Arduino core
"3.20017.x" (numeracion nueva, equivale a Arduino-ESP32 core 3.x sobre IDF 5.x), que es una familia
de IDF totalmente distinta a la v4.4.7 que esta embebida en el binario de 2026-11-02. Si alguien
recompila `main.cpp` HOY en esta maquina con el `platformio.ini` actual (que no fija version de
`platform`), el binario resultante **no sera igual** al original -- platformio.ini no fija una
version (`platform = espressif32` sin `@`), asi que instala lo mas nuevo disponible en cada maquina
nueva.
